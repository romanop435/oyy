Z-BREACH — экран загрузки для GMod
===================================

Файлы:
  index.html, style.css, script.js, img/bg1..bg7.jpg

Как поставить на сервер
-----------------------
GMod умеет показывать экран загрузки только по http(s)-ссылке, поэтому папку
нужно залить на любой хостинг статики:
  - GitHub Pages (бесплатно): новый репозиторий -> залить содержимое этой папки
    -> Settings -> Pages -> Branch: main. Ссылка будет вида
    https://<ник>.github.io/<репо>/
  - или любой веб-хостинг / свой nginx.

Потом в server.cfg:
  sv_loadingurl "https://<ник>.github.io/<репо>/"

Проверить локально: открыть index.html через любой http-сервер
(например, python -m http.server в этой папке) — без GMod включается демо-режим
с фейковой загрузкой.

Что настраивается (script.js, верх файла)
-----------------------------------------
  SLIDES  — картинки, заголовки и подписи слайдов
  SLIDE_TIME — сколько мс висит один слайд
  TIPS    — советы снизу справа
  BOOT    — стартовые строки терминала
Музыка: положить audio/theme.ogg и раскомментировать строку "music = ..."
в script.js. Громкость берётся из настройки громкости музыки игрока.

Название сервера под логотипом подставляется автоматически из hostname.
Код написан под старый движок браузера GMod (Awesomium): только ES5 и
-webkit- префиксы — не переписывайте на современный JS, иначе на основной
ветке игры экран сломается.
